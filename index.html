Course overview

This introductory course helps BCA learners understand computer systems and apply information technology to academic, personal and organisational tasks. Learning combines demonstrations, guided laboratory work, case-based activities, peer learning, a mini-project and reflection.

Course learning outcomes

By the end of the course, learners should be able to:

CO1 · Understand

Explain computer systems

Explain computer architecture, data representation, operating-system concepts and basic IT terminology.

CO2 · Apply

Use productivity tools

Apply productivity, file-management and basic data-handling tools to academic or workplace tasks.

CO3 · Analyse

Analyse connected technologies

Analyse basic networking, internet, database and web concepts in practical contexts.

CO4 · Apply / Evaluate

Practise responsible IT

Apply safe, ethical and responsible practices for cybersecurity, privacy and AI-assisted work.

CO5 · Create

Design a simple solution

Design and present a simple digital solution or workflow using computational thinking and appropriate tools.
